# ことばレンズ

ブラウザだけで動く日本語テキストマイニングツールです。`index.html` をブラウザで開けば使えます（サーバー・インストール不要、文章は外部に送信されません）。

## 機能

- **頻出語**：出現回数・出現文書数・文字種の一覧（CSV をクリップボードにコピー可）
- **ワードクラウド**：出現回数を文字の大きさ、文字種を色で表示
- **共起ネットワーク**：同じ文（または行）に現れる語を Jaccard 係数で結び、まとまりを色分け
- **連続する語**：2語の並び（バイグラム）の頻度
- **KWIC**：語が使われている前後の文脈を一覧表示

表やグラフの語をクリックすると KWIC に移動します。

## 入力

- テキストを直接貼り付け、または `.txt` / `.csv` / `.tsv` を読み込み（UTF-8・Shift_JIS・EUC-JP）
- 1行を1件（アンケートの1回答など）として扱います

## 解析の仕組み

単語分割にはブラウザ内蔵の `Intl.Segmenter`（日本語の単語分割）を使います。品詞情報はないため、
「ひらがなだけの語を除く」「除外する語」の設定で助詞や機能語を取り除きます。
